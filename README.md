# v0.36 — Việt hóa tên module & tinh chỉnh Tổng quan TGĐ

## Tên module mới

1. **Lựa chọn đối tác**
2. **Đàm phán & Thỏa thuận**
3. **Phân tích thị trường**
4. **Lựa chọn trò chơi**
5. **Tìm kiếm cơ hội**
6. **Vận hành phát hành**
7. **Tài liệu nguồn**
8. **Lịch sử thay đổi**

Các tham chiếu chéo trong UI (nguồn dữ liệu, ghi chú “chỉ sửa tại…”, nút mở module, tiêu đề trang) dùng cùng bộ tên trên. Route/key nội bộ không đổi nên không ảnh hưởng dữ liệu, Supabase hay audit log.

## Tổng quan dành cho Tổng Giám Đốc

Đổi **“Cần TGĐ xem”** thành **“Điểm cần lưu ý”**. Mô tả mới: **“Các rủi ro, điểm nghẽn và điều kiện cần theo dõi.”**

Các chart cũng được Việt hóa để đồng nhất:
- **Đối tác nổi bật**
- **Điều khoản hợp tác · Chia sẻ doanh thu**
- **Phễu cơ hội phát hành**
- **Danh mục sau thỏa thuận**
